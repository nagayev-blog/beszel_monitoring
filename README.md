docker-compose файлы  для настройки Beszel Хаба и Агента
на стеке Portainer + Traefik

docker-compose.yml - для хаба (указать в environments DOMAIN на котором будет развернут beszel, предварительно убедиться, что dns запись создана и резолвится)
agent-docker-compose.yml - для установки агента (в env указать HUB_DNS хаба, например beszel.example.com и ключи с хаба (в UI в форме подключения их можно найти)  - BESZEL_TOKEN и BESZEL_KEY)

Для подключения агента обязательно использовать и ключ и токен, чтобы включить режим работы websocket с пушем параметров из агента на хаб - пул настроить проблематично.
Агент подключится автоматически, проверить можно в UI хаба
